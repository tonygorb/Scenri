# Refine a Shot

Refine changes a Shot you already have. It is not a new line from scratch.

## Before you start

You need a finished Shot. [Create a Shot](CREATE.md) if you do not have one. Generation has to be connected, the same as the first picture. [Connect image generation](CONNECT.md).

## Change one thing

1. Open the Shot.
2. Say the one thing to change.
3. Press **Refine**.

The new picture joins the trail under the Shot. The original is first. Each later step is **Refinement 1**, **Refinement 2**, and so on. Any step can be refined again.

A change to one part keeps the rest of the picture as it was. A change that affects the whole frame, such as new light, is free to redraw it. Changing to a wider or taller shape keeps the original photograph and draws the new margin when that leaves no visible join. A tighter shape is a crop.

A refinement carries the Shot's logo unless you removed it.

## Try again and Reuse setup

**Try again** runs the same setup once more, for a different take. On a failed or stopped Shot, it runs again in the same card. It is always a new take. Scenri does not pin a seed.

**Reuse setup** starts a new line in the composer from this Shot: the same prompt, chips, shape, and count, ready to change. Use it for "like this one, but". Use Refine when you want to change this picture.

## What you have at the end

The same Shot, with the trail still under it. Mark it a [Keeper](KEEPERS.md) if it is the one you want to come back to.
