# Mockups v6: imagery-first direction (Studio 5.0)

These five pages are the single visual reference for Studio 5.0. They supersede the v5 pair one directory up.

## Gate rules
1. Approve pixels first. No app code ships until every page here is approved.
2. After approval, implementation matches these pages 1:1.
3. Post-approval feedback is papercuts only (spacing, color values, copy). New directions reopen the gate.

## Pages: app (local OSS studio)
- `home.html` - pill nav, serif-accent greeting, quick-create cards, templates carousel, feed tabs, masonry with honest in-flight shimmer and failed tile, floating composer.
- `create.html` - project canvas: masonry with provenance badges, assets panel (products, templates, colors, recent) plus collapsed rail, floating composer with brief tokens, attached chips, compiled-brief tip line.
- `detail.html` - full-screen overlay: lineage filmstrip, stage with editable text layers (one selected), meta panel (context chips, brief with Remix, size and cost, compare block), suggested-action stack, edit composer. The gate question for this page: can you still read the version tree?
- `detail-edit.html` - the same overlay in text-editing mode: layers list, full type controls (font, size, weight, spacing, align, brand color swatches, effects), snap guide on stage, flatten export. This is the Inspector Text tab absorbed into the overlay.
- `brand.html` - kit page: hero, palette, products (locked shots), favorite looks, danger zone.
- `brand-setup.html` - the four wizard steps stacked for review; in-app each step is its own screen.
- `looks.html` - the looks library, and the replacement for `templates.html`. Full-bleed, no centred column: a sticky vertical rail, collections as sections with their look names listed inline, and a dense mixed-height masonry that runs the width of the window. Nothing is written on a picture; the name, the lighting phrase and the Use CTA all wait for hover.
- `look.html` - one look: centered column, no hero, title with a single italic word, one-line description, and one button. Then: **three 1:1 reference frames** that define the look, expandable to six and deliberately not clickable, a **Created with this look** slider and an **Other looks, similar light** slider, both looping with soft edge fades. The page closes on the looks you would reach for next, rather than on a call to action.

  The Morning Tabletop frames are real, generated by `templates/previews/generate-look-set.mjs` and served from `/api/look-previews/morning-tabletop/`. The other nine looks have no set yet, and the whole set is expected to be redrawn.
- `settings.html` - a **dialog, not a page**, because settings is a detour: you open it mid-brief to paste a key and go back to where you were. The app stays visible behind the scrim. Left rail, one pane at a time, grouped **Generation** (Engines, Budget, Usage) and **This machine** (Library, Appearance, About, Danger zone). Engines carries the default engine and quality for a new brief, then one block per engine with its key beneath rather than crammed into the row. **Budget** is the limit you set: caps in generations first and dollars second, plus what happens when one is reached (fall back to a free engine, warn at 80%). **Usage** is what actually happened: a year of runs as a GitHub-style contribution grid, one square per day with a hover count, then the month by activity, then by engine, then the CSV. The grid uses an ink ramp, not gold, because gold stays reserved for credits, keepers and the shimmer. Danger zone is its own rail item and splits the reversible option (delete shots) from the final one.
- `login.html` - hosted-studio sign in, the screen we never drew. Same split as registration, OAuth first, email beneath, and a rejected-password state. Carries the honest note that the local app has no accounts at all.
- `states.html` - specimen sheet: credits popover, brand switcher, export dialog, compare drift dialog, toasts, empty project, first run, project picker, and the composer's two-sigil grammar: `@` opens ingredients (cast, products, colors, shots), `#` opens looks, and a third specimen shows chips placed with `#F5A623` sitting beside them as plain text, since a hex must never open the look menu.

## Pages: hosted acquisition (scenri.dev, designed ahead of build)
- `landing.html` - marketing LP. The persistent generate dock is the hero hook: it is the SAME component as the in-app composer, fixed to the bottom through the whole scroll. Typing a brief and hitting Generate routes into registration carrying the brief.
- `register.html` - smart registration, 5 steps (profile, work type, categories, taste picker, plans) plus the payoff screen. The smart mechanics:
  1. The LP brief rides the whole flow as a pill top-right of every step, and runs automatically the moment setup finishes. Nobody lands in an empty app.
  2. The profile step asks for the brand website; the kit scrapes and builds itself in the background WHILE the user answers steps 2 to 4. Zero dead waiting.
  3. Plans use the strategy pack hypotheses (Free BYOK $0, Pro $24, Studio $89) and keep a Skip this step escape. Free tier is the real OSS story, not a crippled trial.
- The local OSS app never shows registration; these two pages are the cloud surface only.

## Full flow map
- Anonymous: landing dock -> register (brief carried) -> payoff screen -> studio home with first shots arriving.
- Local first run: first-run state (states.html) -> brand-setup wizard -> home.
- Daily loop: home feed -> create canvas -> detail overlay -> detail-edit for text -> export dialog.
- Discovery: looks library -> one look -> attach to brief -> generate. (`templates.html` was deleted on 2026-08-03: the coupled model it drew is gone from the code as well.)
- Money: credits pill -> credits popover -> settings spend caps.

## System pages
- `system.html` - THE design system sheet: full type scale (display-xl to mono, Inter Tight body, Inter Tight display, Playfair italic accent), 4px spacing scale, radius scale, button variants and sizes, inputs, chips and tokens, surfaces and elevation, color token table, breakpoint rules, non-negotiables. Every other page must resolve to this sheet.
- `responsive.html` - drawn frames: mobile home, mobile detail overlay (stacked, horizontal filmstrip, 24px touch handles), tablet create with assets sheet. Breakpoints: desktop 1280+, tablet 768 to 1279, mobile under 768.

## Locked decisions baked in
- Dual theme, near-black dark (#0d0d0d) and white light. Toggle button bottom-right on every page.
- One gold accent (#F5C518): credits pill, keeper stars, generation shimmer. Nothing else.
- Type: Inter Tight everywhere, weights doing the work. Accent = Playfair Display italic, one phrase per screen, headings only. **No monospace anywhere** (removed 2026-08-03).
- Phosphor-style stroke icons only. No emoji. No long dashes in copy.
- Honest UI: shimmer + elapsed seconds for in-flight (we have status, not progress), real nav items only.
- **Scrollbars**: thin, trackless, thumb tinted from the theme's own ink, 999px radius, 3px transparent inset border so it reads 4px but targets 10px. Defined once per page beside the reset, and once in `apps/studio/src/styles/tokens.css` as `--bt-sb` / `--bt-sb-hover`. Horizontal carousels and tab strips still hide theirs and rely on the peeking next item.
