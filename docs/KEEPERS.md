# Keepers and sets

Both live in Create. Neither is a place in the top bar.

## Keepers

A Keeper is a Shot you marked. In Create, the **Keepers** tab shows only those, inside whatever you are already looking at: all Shots, or one Set.

The same mark exists on a Product, a Presenter, and a Scene. On those pages the tab is also called **Keepers**. It is a shortlist for that library, not a copy of the Shot.

Archiving a Shot clears the Keeper mark. Restore it from **Archived** if you put it away by mistake.

## Sets

A Set is a named group of Shots, such as a campaign or a round for a client. It has its own address in Create.

Open the place menu in Create, choose **New set**, and name it. Add Shots from the selection bar. **Not in a set** is the Shots no Set has claimed. **All shots** is everything.

Deleting a Set does not delete the Shots.

The several cards you get from one line are not a Set. Each is its own Shot. [Create a Shot](CREATE.md).
